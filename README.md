# 🎓 University Management System (Java Swing & MySQL)
A comprehensive, desktop-based management system designed to automate university operations. This project focuses on Object-Oriented Programming (OOP) principles and provides a robust interface for administrators to manage students, teachers, examinations, and fee structures.

---

## 🚀 Key Modules
- **Login System**: Secure administrative access with hashed password handling.
- **Student Management**: Add, Update, and View detailed student records.
- **Teacher Management**: Faculty data handling and campus assignment.
- **Examination Portal**: Specialized module to enter marks and generate student results/grade cards.
- **Fee Management**: Track fee structures and student payment status.
- **Interactive UI**: Built with Java Swing for a seamless and user-friendly experience.

---
  
## 🛠️ Tech Stack
- **Language**: Java 21 (JDK)
- **GUI Framework**: Java Swing & AWT
- **Database**: MySQL Server
- **Architecture**: JDBC (Java Database Connectivity)
- **Libraries**: RS2XML, JCalendar, Apache POI
